## Dense OpenCode workload

Command: `timeout -k 10 120 uv run python scripts/benchmark_usage_opencode.py --baseline 588ae960d6e6ae88668a4aa6325955c1719173fe`.

The [OpenCode procedure](../README.md#dense-opencode-comparison) generated a 52.4 MiB database
with 100,000 assistant and 100,000 user messages, 500 sessions and 50 projects. It measured
three baseline all-time runs and four current all-time runs, then the current seven-day report
cold, warm and under a separate cache read transaction. No separate warmup was used.
Each invocation ran in a fresh process; peak RSS is process memory in MiB.
[Raw measurements](2026-11-21-final-opencode.json).

| Measurement | Baseline all-time median | Current all-time cold | Current all-time repeat median |
|---|---:|---:|---:|
| Wall time (seconds) | 1.507 | 1.554 | 1.472 |
| Peak RSS (MiB) | 110.9 | 111.8 | 111.4 |

Every comparable JSON result matched. The oversized all-time result remained uncached and
read SQLite on each run, with memory near baseline. The seven-day result occupied 0.797 MiB
in the cache: cold/warm/contended wall times were 0.164/0.118/0.117 seconds. Warm and contended
reads issued no source queries, and the ordinary warm hit left cache mtime unchanged.
